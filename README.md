# In vivo image compilation

`in_vivo_image_compilation.py` imports cSLO and OCT retinal images, collects metadata through a settings dialog, and generates a compiled summary image (.jpg) showing all images organized by mouse, eye, and image type. The entire workflow is controlled through a Tkinter GUI.

## Output

A single `.jpg` image file containing all selected images arranged in a grid, with mouse IDs, eye labels, and optional group/date headings.

## Requirements

- Input images must be in JPG, PNG, TIF, or BMP format.
- cSLO and OCT images must follow specific naming and folder conventions 
  (described below).

### cSLO Images

Images must be organized into the following folder structure:
	root_folder/
		mouseNumber/
			OD/
				imageNumber_mouseNumber_OD_modality.tif
			OS/
				imageNumber_mouseNumber_OS_modality.tif

Files must follow this naming format:
	imageNumber_mouseNumber_eye_modality

For example: `001_42_OD_BAF.tif`

The script also supports a `_standardized` subfolder structure (e.g., `OD_standardized/`) generated by the companion script `conform_cslo_image_pattern.py`. If a standardized folder is present, it will be used in place of the original.

### OCT Images

All OCT images should be stored together in a single flat folder. Files must follow this naming format:
	mouseNumber_eye_modality

For example: `42_OD_horizontal.tif`

## Features

- **Mouse metadata**: Assign lab IDs, groups, and exclude individual mice
- **Group & date organization**: Arrange mice by treatment group or imaging date
- **OCT auto-crop**: Automatically centers and crops OCT images around the retina
- **cSLO text crop**: Optionally removes the text strip from the bottom of cSLO images
- **Previous settings**: Saves and reloads your last configuration automatically
- **Conform cSLO image order**: Launches `conform_cslo_image_pattern.py` to standardize image sequences before compilation

## Companion Scripts

This tool is designed to work alongside:
- `cSLO_image_download` — Downloads and organizes raw cSLO images from Heidelberg Eye Explorer (https://github.com/banderson314/cSLO_image_download)
- `Convert_OCT_files_to_TIF` — Converts .OCT files to TIF format (https://github.com/banderson314/Convert_OCT_files_to_TIF)
- `conform_cslo_image_pattern.py` and `export_worker.py` — Standardizes cSLO image sequences into a consistent pattern for proper layout. These scripts need to be in the same folder as in_vivo_image_compilation.py if used, but are not necessary for in_vivo_image_compilation.py to run.

## Notes

This tool was developed primarily for mouse research. As a result, several internal variable names use "mouse" or "mice."
